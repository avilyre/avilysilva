# Dependencies
- None

# Acceptance Criteria
- Ao final de qualquer artigo do blog, existe um bloco de recomendação de próxima leitura (quando houver posts recomendáveis).
- O bloco exibe uma lista com até 3 itens, ordenados do mais recente para o menos recente.
- Cada item exibe somente:
  - Título do conteúdo
  - Resumo do conteúdo
- O item é clicável e direciona o leitor para a página do conteúdo recomendado.
- O artigo atual nunca aparece como item recomendado.
- Se não existir nenhum outro conteúdo disponível além do atual, o bloco de recomendação não é exibido.
- Se existirem apenas 1 ou 2 conteúdos disponíveis (excluindo o atual), o bloco é exibido com somente 1 ou 2 itens, respectivamente.
